Prime Explorer

Check whether a whole number is prime. The same algorithm runs in this browser and in the tested Node.js module.

Enter a number and select “Check number”.

How it works

We reject values below 2, handle even numbers immediately, then test odd divisors only up to the square root. Large inputs are capped to keep the page responsive.
