# freeCodeCamp Back-End Development and APIs — Certification Projects

Independent Node.js back-end projects implemented and tested as part of freeCodeCamp's project-based curriculum.

## 1. Prime Number Checker Module
- CommonJS module exporting `isPrime`.
- Rejects non-integer, unsafe, negative and non-numeric inputs.
- Runs primality check in O(sqrt(n)) time and O(1) auxiliary space.
- Test with `cd build-a-prime-number-checker-module && npm test`.

Additional certification projects will be included as each project passes its own tests.
